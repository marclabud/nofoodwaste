# SRF Einstein – Brand Research

## Übersicht

Die Sendung „Einstein“ von SRF verwendet eine moderne wissenschaftlich-technische Designsprache mit starken Kontrasten, klaren UI-Elementen und datenorientierter Ästhetik.

Die Gestaltung kombiniert:
- SRF Brand-Elemente
- dunkle technische Oberflächen
- helle Daten- und Informationsflächen
- Cyan- und Blau-Akzente
- reduzierte moderne Typografie

## Designcharakter

### Stilrichtungen

- Scientific UI
- Broadcast Design
- Data Visualization
- Modern Tech Interface
- Editorial Science Design

### Wahrnehmung

| Eigenschaft | Wirkung |
|---|---|
| Dunkle Oberflächen | technisch, seriös |
| SRF Rot | Energie, Marke |
| Cyan/Blau | Forschung, Daten |
| Hoher Kontrast | Präzision |
| Helle Flächen | Klarheit |
